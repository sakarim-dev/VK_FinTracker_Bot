# VK_FinTracker_Bot — исправленная версия

## Что изменено

1. Исправлен сценарий добавления дохода/расхода.
2. Категории, подкатегории, «Назад», «Отмена», «Пропустить» и подтверждение удаления переведены на inline callback-кнопки.
3. Главное меню осталось обычной клавиатурой.
4. Исправлено удаление последней записи: исходный код искал колонку `Кто добавил`, хотя запись сохранялась в колонку `ID`.
5. Удалена активная логика статистики и отчётов. Модули-заглушки сохранены для будущего подключения.
6. Income/expense объединены в единый transaction handler.
7. Все обработчики используют один `CtxStorage`.
8. Запись в Google Sheets переведена на `append_row`, без полного сканирования листа при каждом добавлении.
9. Добавлены комментарии, логирование и более единообразная обработка ошибок.

## Важно про callback-кнопки

Callback-кнопки VK приходят как `MESSAGE_EVENT`, а не как обычные сообщения. Поэтому в `bot.py` есть единый обработчик callback-событий. Это соответствует модели VKBottle для `MessageEvent`. Для работы inline callback-кнопок сообщество должно корректно принимать события сообщений. 

## Запуск

1. Создайте `.env` с `VK_TOKEN`, `TABLE_ID` и при необходимости `ALLOWED_USERS`.
2. Положите `credentials.json` в корень проекта.
3. Установите зависимости: `pip install -r requirements.txt`.
4. Запустите `python bot.py`.

## Структура

- `bot.py` — точка входа и единый callback dispatcher.
- `handlers/transaction.py` — общий сценарий доходов/расходов.
- `handlers/delete.py` — удаление последней записи.
- `handlers/start.py` — старт и главное меню.
- `handlers/navigation.py` — legacy-совместимость.
- `keyboards.py` — все клавиатуры.
- `state.py` — единое состояние пользователей.
- `sheets.py` — слой доступа к Google Sheets.
- `handlers/stats.py`, `handlers/reports.py` — задел под будущие функции.
